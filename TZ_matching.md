Часть 2 — Задача маппинга категорий

Это классическая задача семантического матчинга. Модель справится, но важно правильно составить промпт.

Ключевые моменты:

- Не кидать весь JSON сразу если он большой — модель может "потеряться"
- Давать категории батчами (по 20-50 за раз)
- Просить отвечать строго в JSON без лишнего текста
- Указывать правила: только конечные узлы референса, одна категория → одно соответствие

Шаблон промпта:
Ты эксперт по классификации товаров интернет-магазина.

ЗАДАЧА: Для каждой категории из списка SOURCE найди наиболее подходящую
конечную категорию из дерева REFERENCE. Совпадение по смыслу и контексту,
не обязательно точное по названию.

ПРАВИЛА:

- Выбирай ТОЛЬКО конечные (листовые) категории из REFERENCE
- Каждой SOURCE категории — одно соответствие
- Если нет подходящей — пиши null
- Отвечай ТОЛЬКО валидным JSON, без пояснений

REFERENCE (дерево):
{reference_json}

SOURCE (категории для маппинга):
{source_batch}

ОТВЕТ (JSON):
[
{"source_id": "...", "source_name": "...", "mapped_to_id": "...", "mapped_to_name": "..."},
...
]
