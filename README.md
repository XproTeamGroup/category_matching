# Система автоматического сопоставления категорий

**Высокопроизводительная система** для автоматического сопоставления категорий товаров из внешних источников с существующими категориями в базе данных с использованием Claude API для интеллектуального анализа и сопоставления.

## ⚡ Ключевые особенности

- **Масштабируемость**: Обработка от сотен до миллионов категорий
- **Интеллектуальная фильтрация**: Многоуровневая система предварительной фильтрации
- **Векторный поиск**: TF-IDF векторизация с косинусным сходством
- **Многоуровневое кеширование**: Memory + SQLite + Persistent кеши
- **Мониторинг производительности**: Детальная аналитика и рекомендации
- **Параллельная обработка**: Асинхронная обработка батчей
- **Автоматическая оптимизация**: Адаптация под размер данных

## 🚀 Быстрый старт

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка

Установите переменную окружения с вашим API ключом Claude:

```bash
export CLAUDE_API_KEY="your-api-key-here"
```

### Базовый запуск

```bash
python main.py --reference data/input/reference_categories.json \
               --input data/input/input_categories.json \
               --output data/output/results.json
```

## ⚙️ Конфигурация

Основные настройки в `config/settings.py`:

```python

# Минимальная уверенность для сопоставления  
CONFIDENCE_THRESHOLD = 0.7
```

## 📝 Использование

### Основные параметры

- `--reference` - путь к файлу справочных категорий
- `--input` - путь к файлу входных категорий
- `--output` - путь к выходному файлу
- `--batch-size` - размер батча (по умолчанию: 15)
- `--confidence-threshold` - минимальный порог уверенности (по умолчанию: 0.7)

### Дополнительные опции

```bash
# С дополнительными файлами результатов
python main.py --reference data/input/reference_categories.json \
               --input data/input/input_categories.json \
               --output data/output/results.json \
               --summary-file data/output/summary.txt \
               --unmatched-file data/output/unmatched.json

# Отладочный режим
python main.py --reference data/input/reference_categories.json \
               --input data/input/input_categories.json \
               --output data/output/results.json \
               --log-level DEBUG \
               --show-stats \
               --no-prefilter
```

## 📊 Производительность и масштабирование

### Автоматическое переключение режимов

Система автоматически переключается между режимами в зависимости от объема данных:

| Размер справочника | Режим | Особенности |
|-------------------|--------|-------------|
| < 200 категорий | Стандартный | Простая фильтрация, прямая обработка |
| 200-10,000 | Оптимизированный | Продвинутая фильтрация, индексы |
| > 10,000 | Большие данные | Векторный поиск, чанкинг, параллелизм |

### Производительность

- **Малые данные** (< 200): ~5-10 категорий/сек
- **Средние данные** (200-10K): ~20-50 категорий/сек  
- **Большие данные** (> 10K): ~100-500 категорий/сек

### Оптимизации

1. **Многоуровневая фильтрация**:
   - Ключевые слова → N-граммы → Нечеткое сравнение → Векторное сходство

2. **Интеллектуальное кеширование**:
   - LRU Memory кеш для горячих данных
   - SQLite для persistent хранения
   - Автоматическая очистка по TTL

3. **Параллельная обработка**:
   - Асинхронные API запросы
   - Многопоточная фильтрация
   - Чанкинг больших файлов

## 🔍 Алгоритм работы

1. **Загрузка данных** - загружает справочные и входные категории
2. **Предобработка** - строит индексы и дерево категорий
3. **Предфильтрация** - оптимизирует список для обработки
4. **Батчевая обработка** - группирует категории и отправляет в Claude API
5. **Постобработка** - валидирует и дополняет результаты
6. **Экспорт** - сохраняет результаты в указанном формате

## 🎯 Особенности

- **Интеллектуальное сопоставление** с использованием Claude API
- **Батчевая обработка** для оптимизации запросов и снижения стоимости
- **Кеширование результатов** для ускорения повторных запросов
- **Предварительная фильтрация** по ключевым словам и нечеткому поиску
- **Подробная статистика** и логирование процесса
- **Гибкая настройка** порогов уверенности и размеров батчей

## 📈 Оптимизация производительности

- Используется **Claude Sonnet 4** (оптимальное соотношение цена/качество)
- **Батчевая обработка** до 15 категорий в одном запросе
- **Предварительная фильтрация** снижает количество категорий для обработки
- **Кеширование** избегает повторных API запросов
- **Асинхронная обработка** для ускорения работы

## 🔧 Устранение неполадок

### Распространенные проблемы

1. **Ошибка API ключа**
   ```
   Убедитесь, что установлена переменная CLAUDE_API_KEY
   export CLAUDE_API_KEY="your-key"
   ```

2. **Низкий процент совпадений**
   ```bash
   # Снизьте порог уверенности
   python main.py ... --confidence-threshold 0.5
   
   # Отключите предфильтрацию
   python main.py ... --no-prefilter
   ```

3. **Медленная работа**
   ```bash
   # Увеличьте размер батча
   python main.py ... --batch-size 20
   ```
