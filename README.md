# Category Matching Tool

Универсальный инструмент для семантического сопоставления категорий двух каталогов.
Работает с любым доменом — AI сам определяет домен из reference-дерева, без хардкода.

---

## Быстрый старт

```bash
# Установить зависимость
pip install python-dotenv

# Скопировать и заполнить конфиг
cp .env.example .env

# Запустить
py main.py
```

---

## Входные файлы

`reference.json` — эталонное дерево категорий (цели для маппинга).
`source.json` — плоский или иерархический список категорий, которые нужно сопоставить.

Формат обоих файлов — массив объектов:

```json
[
  { "id": "123", "parent_id": null, "name": "Ножі", "final": "1", ... },
  { "id": "124", "parent_id": "123", "name": "Складні ножі", "final": "1", ... }
]
```

Поля `id`, `parent_id`, `name`, `final` обязательны. Остальные игнорируются.
`final: "1"` — листовая категория (допустимая цель для матчинга).

---

## Запуск

```bash
# Стандартный: прямой матчинг + AI
py main.py

# С force-match: AI второй проход + классификация out_of_scope
py main.py --force-match

# С few-shot примерами: повышает точность AI
py main.py --examples examples.json

# С верификацией: AI проверяет каждый свой матч
py main.py --verify

# Кастомные файлы
py main.py --reference ref.json --source src.json

# Только прямой матчинг, без AI
py main.py --skip-ai

# Показать статистику без сохранения файлов
py main.py --dry-run

# Все опции вместе
py main.py --force-match --examples examples.json --verify
```

# Глубокий метчинг
py main.py --deep
```

## Метрики результата

```

=======================================================
РЕЗУЛЬТАТИ МАТЧИНГУ
=======================================================
Всього source категорій : 537
Поза доменом (out_of_scope) : 258
Потенційно сматчуваних : 279
Сматчено : 238
Не сматчено : 41
Відсоток (від усіх) : 44.3%
Відсоток (від сматчуваних) : 85.3%
Відхилено верифікацією : 41

По методах:
normalized : 23
exact : 13
ai : 179
ai_force : 23
=======================================================

````

| Метрика | Що означає |
|---|---|
| **Всього source категорій** | Общее количество категорий во входном `source.json` |
| **Поза доменом (out_of_scope)** | Категории, которые AI определил как полностью вне домена reference-дерева. Появляется только при `--force-match`. Это не ошибка — это правильный null: категории физически не могут быть сопоставлены, потому что в reference нет такого домена. |
| **Потенційно сматчуваних** | `Всього` минус `out_of_scope` — реальное количество категорий, для которых теоретически существует match в reference. Знаменатель для "правильного" процента. |
| **Сматчено** | Количество source-категорий, которым найдена категория в reference. Включает все методы: exact, normalized, ai, ai_force. |
| **Не сматчено** | Остаток после всех проходов. Категории в домене reference, но конкретного места для них нет. Требуют ручной проверки. |
| **Відсоток (від усіх)** | `Сматчено / Всього source`. Показывает общий охват включая out_of_scope. Всегда будет низким если source содержит много категорий вне домена. |
| **Відсоток (від сматчуваних)** | `Сматчено / Потенційно сматчуваних`. **Основная метрика качества** — показывает насколько хорошо работает матчинг в рамках того, что вообще можно сматчить. 85% = из 279 реально сматчиваемых категорий найдено 238. |
| **Відхилено верифікацією** | Количество AI-матчей, которые модель отклонила при верификации (`--verify`). Эти пары переходят в `unmatched.json` для ручного просмотра. Высокое число = AI в основном проходе делал много натяжек. |

### Методы матчинга

| Метод | Когда срабатывает | Уверенность |
|---|---|---|
| **exact** | Название source точно совпадает с названием reference (без учёта регистра) | Высокая |
| **normalized** | Совпадение после удаления брендов (латиница), серийных маркеров и цифр. Пример: "Ganzo мультитули" → "мультитули" = "Мультитули" | Высокая |
| **ai** | Семантическое сопоставление через AI. Стандартный промпт: balanced, null если нет хорошего match | Средняя |
| **ai_force** | AI второй проход (`--force-match`) с более настойчивым промптом. Также возвращает `out_of_scope: true/false` | Средняя |

## Выходные файлы

Все файлы сохраняются в папку `output/`.

| Файл | Содержимое |
|---|---|
| `mapping.json` | Финальный маппинг для импорта в БД: `source_id → reference_id` с метаданными |
| `mapping.csv` | То же самое в CSV для просмотра в Excel |
| `unmatched.json` | Source-категории без матча — для ручного разбора |
| `out_of_scope.json` | Категории вне домена reference (только при `--force-match`) |
| `verify_rejected.json` | Матчи, отклонённые верификацией (только при `--verify`) |
| `stats.json` | Полная статистика в JSON |

### Формат mapping.json

```json
[
  {
    "source_id": "24430",
    "source_name": "Ganzo мультитули",
    "reference_id": "24323",
    "reference_name": "Мультитули",
    "reference_path": "Ножі та інструменти > Мультитули",
    "method": "normalized",
    "confidence": "high"
  }
]
````

## --examples: few-shot примеры

Файл `examples.json` — массив известных правильных матчей:

```json
[
  {
    "source_name": "Ganzo мультитули",
    "reference_path": "Ножі та інструменти > Мультитули"
  },
  {
    "source_name": "Масла і мастила Brunox",
    "reference_path": "Чистка та догляд > Засоби"
  }
]
```

Примеры добавляются в промпт как образец. Чем больше примеров (10–20) — тем лучше,
особенно для неоднозначных категорий. Скопируй `examples.json.example` → `examples.json` и дополни своими данными.

---

## --verify: верификация матчей

После матчинга AI проверяет каждую пару `(source, reference)` отдельным запросом:
"Эта пара корректна?"

- Верифицируются только `ai` и `ai_force` матчи (exact/normalized — высокая уверенность, не нуждаются в проверке)
- Отклонённые пары → `verify_rejected.json` + переходят в `unmatched.json`
- Высокий процент отклонённых = стоит добавить больше `--examples`
