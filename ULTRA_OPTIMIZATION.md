# Ультра-оптимизация системы сопоставления категорий

## Проблемы которые решаем

1. **Слишком много API запросов**: Раньше каждая категория = 1 API запрос
2. **Обработка всех категорий**: Включая родительские категории, которые не нужны
3. **Отсутствие умной предфильтрации**: AI обрабатывает даже очевидные совпадения
4. **Низкая производительность**: При 6000 категорий = 6000 API запросов

## Решения

### 1. Фильтрация только конечных категорий (листья дерева)
- **Что делает**: Обрабатывает только категории без дочерних элементов
- **Эффект**: Снижение количества справочных категорий на 30-70%
- **Файл**: `src/ultra_optimized_processor.py:filter_leaf_categories_only()`

### 2. Умная предварительная фильтрация (Auto-matching)
- **Что делает**: Автоматически матчит категории с similarity >= 0.9 БЕЗ AI
- **Использует**:
  - Словарь синонимов из SmartMatcher
  - Точные совпадения после нормализации
  - Высокое текстовое сходство (95%+)
- **Эффект**: 40-80% категорий матчатся автоматически
- **Файл**: `src/ultra_optimized_processor.py:smart_pre_filter()`

### 3. Батчевая обработка AI запросов
- **Что делает**: Обрабатывает 15-20 категорий в одном API запросе вместо 15-20 запросов
- **Эффект**: Сокращение API запросов в 15-20 раз
- **Файл**: `src/ultra_optimized_processor.py:_batch_process_with_ai()`

### 4. Релевантная предфильтрация справочных категорий
- **Что делает**: Для каждого батча выбирает только 100 наиболее релевантных справочных категорий
- **Эффект**: Ускорение обработки AI, уменьшение размера промптов
- **Файл**: `src/ultra_optimized_processor.py:_get_most_relevant_categories()`

## Результаты оптимизации

### До оптимизации (6000 категорий):
- API запросов: **6000**
- Время обработки: **~30-60 минут**
- Стоимость: **высокая**

### После ультра-оптимизации (6000 категорий):
- API запросов: **~100-300** (сокращение в 20-60 раз!)
- Время обработки: **~2-5 минут** (ускорение в 10-30 раз!)
- Стоимость: **значительно ниже**

## Как использовать

### Стандартный режим (старый):
```bash
python main.py --reference data/reference_categories.json \
               --input data/input_categories.json \
               --output data/output.json
```

### Ультра-оптимизированный режим (новый):
```bash
python main.py --reference data/reference_categories.json \
               --input data/input_categories.json \
               --output data/output.json \
               --ultra-optimize \
               --batch-size 20
```

## Компоненты системы

1. **UltraOptimizedProcessor** - основной движок оптимизации
2. **SmartMatcher** - умное сопоставление синонимов
3. **Leaf filtering** - фильтрация конечных категорий
4. **Batch processing** - батчевая обработка AI
5. **Relevance filtering** - релевантная предфильтрация

## Рекомендации

- Используйте `--ultra-optimize` для всех больших наборов данных (>500 категорий)
- Увеличьте `--batch-size` до 20-25 для максимальной эффективности
- Мониторьте статистику автоматических совпадений
- При низкой доле автоматических совпадений расширьте словарь синонимов в SmartMatcher
