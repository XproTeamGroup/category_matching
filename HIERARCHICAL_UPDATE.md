# Иерархическая система сопоставления категорий - ОБНОВЛЕНИЕ

## 🎯 Что изменилось

Система была полностью переработана для поддержки **иерархических структур** в input файлах с оптимизацией расходов на AI.

### ✅ Решенные проблемы

1. **Поддержка path в input файлах** - теперь input файлы имеют структуру `{"id": "123", "name": "Name", "path": "parent>child>123"}`
2. **Разрешение неоднозначности** - если в reference есть несколько категорий с одинаковым названием (например, "Аксессуары" в ветках мотоциклов и автомобилей), система использует контекст пути для правильного сопоставления
3. **Обработка только листьев** - система автоматически определяет и обрабатывает только конечные категории (листья дерева)
4. **Группировка по веткам** - input категории группируются по целевым веткам reference для оптимальной batch обработки
5. **Экономия на AI** - до 80% запросов экономится за счет точного сопоставления и умной предфильтрации

## 🚀 Новый формат данных

### Reference файл (без изменений)
```json
[
  {"id": "1000", "name": "Мотоциклы", "path": "1000"},
  {"id": "1003", "name": "Аксессуары", "path": "1000>1003"}, 
  {"id": "1004", "name": "Шлемы", "path": "1000>1003>1004"},
  {"id": "2000", "name": "Автомобили", "path": "2000"},
  {"id": "2003", "name": "Аксессуары", "path": "2000>2003"},
  {"id": "2004", "name": "Чехлы", "path": "2000>2003>2004"}
]
```

### Input файл (НОВЫЙ формат)
```json
[
  {"id": "input_1", "name": "Шлемы", "path": "input_moto>input_accessories>input_1"},
  {"id": "input_2", "name": "Чехлы", "path": "input_auto>input_accessories>input_2"}
]
```

## 🔧 Как использовать

### Новая команда (рекомендуется)
```bash
python main_hierarchical.py --reference reference.json \
                            --input input.json \
                            --output results.json
```

### С отладкой
```bash
python main_hierarchical.py --reference reference.json \
                            --input input.json \
                            --output results.json \
                            --debug-trees \
                            --summary-file summary.txt
```

## 🎯 Ключевые особенности

1. **Path-based disambiguation** - "Аксессуары" из input ветки мотоциклов попадает в "Мотоциклы > Аксессуары", а не в "Автомобили > Аксессуары"

2. **Leaf-only processing** - система обрабатывает только конечные узлы, игнорируя промежуточные категории

3. **Branch grouping** - категории группируются по целевым веткам для оптимальной AI обработки

4. **Smart exact matching** - автоматическое сопоставление категорий с одинаковыми названиями без AI

5. **Enhanced prompting** - AI получает полный контекст иерархии для точного сопоставления
