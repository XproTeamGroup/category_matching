# Інструкція з перекладу категорій

## Опис
Скрипти автоматично перекладають назви категорій з польської на українську, використовуючи Claude API.

### Доступні версії:
- `translate_categories.py` - базова версія
- `translate_categories_v2.py` - покращена версія з підтримкою .env файлу та прогресом
- `run_translation.bat` - зручний запуск для Windows

## Вимоги
- Python 3.7+
- Бібліотека `anthropic`
- API ключ від Anthropic

## Встановлення

1. Встановіть необхідну бібліотеку:
```bash
pip install anthropic
```

2. Встановіть API ключ як змінну середовища:

**Windows (CMD):**
```cmd
set ANTHROPIC_API_KEY=your_api_key_here
```

**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="your_api_key_here"
```

**Linux/Mac:**
```bash
export ANTHROPIC_API_KEY=your_api_key_here
```

## Використання

### Варіант 1: Використання .env файлу (рекомендовано)

1. Створіть файл `.env` з вашим API ключем:
```bash
cp .env.example .env
```

2. Відредагуйте `.env` та вкажіть ваш ключ:
```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxx
```

3. Запустіть покращену версію:
```bash
python translate_categories_v2.py
```

### Варіант 2: Windows BAT файл

Просто запустіть `run_translation.bat` - він автоматично встановить залежності та запитає API ключ.

### Варіант 3: Базова версія

Встановіть змінну середовища та запустіть:
```bash
set ANTHROPIC_API_KEY=your_key
python translate_categories.py
```

## Що робить скрипт?

Скрипт автоматично:
1. Обробляє файли `2.json`, `3.json`, `4.json`
2. Перекладає всі назви категорій з польської на українську
3. Зберігає результати у файли `2_translated.json`, `3_translated.json`, `4_translated.json`

## Особливості

### Загальні для обох версій:
- **Розпізнавання брендів**: Скрипт визначає бренди та не перекладає їх назви
- **Рекурсивна обробка**: Перекладає всі рівні вкладеності категорій
- **Затримка між запитами**: Автоматична затримка 0.5 сек між запитами до API

### Додатково у версії v2:
- **Підтримка .env файлу**: Не потрібно вводити API ключ кожен раз
- **Лічильник прогресу**: Показує скільки категорій перекладено (напр. [15/150])
- **Підрахунок категорій**: Показує загальну кількість перед початком
- **Покращений інтерфейс**: Зручний вивід з емодзі та кольоровими повідомленнями
- **Детальна статистика**: Підсумок після завершення роботи

## Налаштування

Ви можете змінити параметри у коді:
- `delay` - затримка між запитами (за замовчуванням 0.5 сек)
- `model` - модель Claude (за замовчуванням "claude-3-5-sonnet-20241022")
- `max_tokens` - максимальна довжина відповіді (за замовчуванням 100)

## Примітки

⚠️ Увага: Обробка великих файлів може зайняти багато часу та коштуватиме кредити API.

💡 Порада: Перевірте перекладені файли перед використанням у продакшені.
