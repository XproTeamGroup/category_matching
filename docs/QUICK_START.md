# 🚀 Швидкий старт

## Найшвидший спосіб запуску (Windows)

1. **Подвійний клік** на `run_translation.bat`
2. Введіть ваш API ключ від Anthropic
3. Чекайте завершення

Готово! ✅

---

## Альтернативний спосіб (з .env файлом)

1. Скопіюйте `.env.example` у `.env`:
   ```bash
   copy .env.example .env
   ```

2. Відредагуйте `.env` та додайте ваш API ключ:
   ```
   ANTHROPIC_API_KEY=sk-ant-your-key-here
   ```

3. Запустіть:
   ```bash
   python translate_categories_v2.py
   ```

## ❓ Де взяти API ключ?

1. Зареєструйтеся на https://console.anthropic.com/
2. Перейдіть у розділ API Keys
3. Створіть новий ключ
4. Скопіюйте його (починається з `sk-ant-`)

## ⚙️ Вимоги

- Python 3.7 або новіший
- Бібліотека `anthropic` (встановиться автоматично)

## 💡 Підказки

- Переклад може зайняти **багато часу** (залежить від кількості категорій)
- Це коштуватиме **API кредити** (приблизно $0.003 на 1000 токенів)
- Можете перервати процес натиснувши `Ctrl+C`
- Результати зберігаються одразу після завершення кожного файлу

## 🆘 Проблеми?

### Помилка: "Python не знайдено"
➡️ Встановіть Python з https://www.python.org/downloads/

### Помилка: "API ключ не встановлено"
➡️ Перевірте що ви створили файл `.env` або встановили змінну середовища

### Помилка: "Файл не знайдено"
➡️ Переконайтеся що файли `2.json`, `3.json`, `4.json` знаходяться у тій же папці
