Проанализируй три JSON файла со структурами категорий (2_1.json, 3_1.json, 4_1.json) и создай на их основе единую оптимизированную структуру категорий

  ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ:

  Структура и качество:
  1. Максимальная глубина вложенности: 4 уровня
  2. Количество главных (корневых) категорий: 8-11
  3. Язык: исключительно украинский
  4. Все категории должны иметь четкие, понятные названия

  Содержание:
  5. Используй ТОЛЬКО категории, присутствующие в исходных файлах
  6. Не создавай категорию "Інше" или аналогичные размытые категории
  7. Все категории должны быть конкретными и понятными пользователю
  8. Исключи дублирование - каждая категория должна встречаться только один раз

  Логика группировки:
  9. Структурируй категории логично, объединяя схожие по смыслу
  10. Обеспечь, чтобы при последующем сопоставлении категорий из исходных файлов с новой структурой не возникало проблем
  11. Товары из любой категории исходных файлов должны однозначно находить свое место в новой структуре

  ФОРМАТ ВЫВОДА:
  12. JSON структура с полями: id, name, children (если есть подкатегории) Четкая иерархия с правильной вложенностью

  ПРОЦЕСС РАБОТЫ:
  13. Сначала проанализируй все три файла и выпиши основные группы категорий
  14. Определи оптимальные главные категории (8-11 штук)
  15. Распредели все подкатегории из исходных файлов по новой структуре
  16. Проверь на дублирование и логичность
  17. Выведи финальную структуру в формате JSON в файл
  18. Не пиши скрипты для создания структуры, пользуйся только своим интелектом, скрипты можно писать только для анализа файлов
